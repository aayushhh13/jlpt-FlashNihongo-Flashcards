## ✨ What is it?

A single-page flashcard app with two modes. You never type anything, you only tap.

| | 🔵 Vocab practice | 🔴 Kanji practice |
|---|---|---|
| Cards | 1,430 words (N5 + N4) | 282 kanji (N5 + N4) |
| Front | Japanese word or meaning (your choice) | Big kanji or meaning (your choice) |
| Back | Meaning, reading, example sentence | Meaning, on-yomi, kun-yomi, example words |
| Theme | Blue | Light red |

Your progress is saved in your own browser, separately for vocab and kanji.

## 🚀 Quick start

1. Click **▶ Open the app** above.
2. Tap anywhere on the start screen.
3. Choose **Vocab practice** or **Kanji practice**.
4. Tap the card to flip it, then press **I know it** or **Still learning**.

<details>
<summary><b>📱 Controls (click to expand)</b></summary>

<br>

| Action | Phone | Keyboard |
|---|---|---|
| Flip card | Tap the card | `Space` or `Enter` |
| Next / previous | Swipe left / right, or the arrow buttons | `→` / `←` |
| Still learning | Button | `1` |
| I know it | Button | `2` |
| Hear a word | Tap the speaker or a word row | `S` |
| Pick a mode on the start screen | Tap | `1` vocab, `2` kanji |

</details>

<details>
<summary><b>⚙️ Options (click to expand)</b></summary>

<br>

- **Card order:** shuffle or in order
- **Cards to study:** all cards, or only the ones you are still learning
- **Front of card:** show the Japanese first or the meaning first
- **Kanji only:** pick a single lesson, and show or hide the example words
- **Reshuffle** and **Reset progress** (tap twice to confirm)

</details>

## 📤 Put it on GitHub Pages

> [!TIP]
> The app is one file, so there is nothing to build. GitHub only needs a file called **`index.html`** in the root of the repo.

- [ ] Open your repo and click **Add file → Upload files**
- [ ] Drag in `index.html` (it replaces the old one)
- [ ] Click **Commit changes**
- [ ] Go to **Settings → Pages**
- [ ] Set **Source** to *Deploy from a branch*, branch **main**, folder **/ (root)**, then **Save**
- [ ] Wait one or two minutes, then open `https://YOUR-USERNAME.github.io/YOUR-REPO/`

<details>
<summary><b>❓ Something is not working (click to expand)</b></summary>

<br>

- **The page shows 404:** the file must be named exactly `index.html`, in lowercase, in the root of the repo.
- **I still see the old version:** wait a minute, then hard refresh (`Ctrl + F5` on a computer; on a phone, clear the site data).
- **My progress disappeared:** progress lives in the browser and is tied to the site address. A new address, a different browser or cleared site data starts fresh.
- **There is no sound:** speech uses your device's Japanese voice. If none is installed, the speaker button has nothing to play.

</details>
